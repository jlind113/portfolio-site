# MJF Home Solutions - Project Summary

## Overview
MJF Home Solutions is a production-ready single-page business website built for a Utah-based home improvement company. The site showcases drywall, carpentry, ceiling texture, and flooring services, highlights completed work through a filterable gallery, and provides a structured customer inquiry flow through a contact form.

## Objective
Design and develop a fast, modern marketing website that helps a local contractor:
- Clearly communicate services and credibility
- Showcase project quality visually
- Convert visitors into leads through an accessible contact experience

## My Role
Full-stack frontend developer (solo project):
- Planned app structure, route architecture, and component system
- Implemented UI/UX with responsive behavior across desktop and mobile
- Built a reusable design system with custom Material UI theming
- Structured service content and imagery for maintainability and future growth
- Configured deployment-ready SPA behavior for Netlify hosting

## Tech Stack
- React 19 + React Router 7 (SPA mode)
- Vite build tooling
- Material UI v7 + Emotion styling
- Tailwind CSS (utility support)
- React Slick carousel for service/gallery media
- Netlify deployment with SPA redirect handling

## Key Features Delivered
- Multi-route SPA: Home, Services, Gallery, and Contact pages
- Custom light/dark theme toggle via Material UI color schemes
- Responsive navigation with desktop links and mobile drawer menu
- JSON-driven service architecture powering service detail views and media
- Filterable project gallery with category chips and dynamic image counts
- Structured lead form with service selection checkboxes and customer details
- SEO-focused per-route metadata (title, description, OG tags, keywords, geo tags)
- Reusable component library for sections such as hero, testimonials, FAQ, cards, and footer

## Technical Highlights
- Implemented a centralized theme in `CustomTheme.jsx` with branded palettes, typography hierarchy, and shared token usage across components.
- Organized content in `ServiceInfo.jsx` so service pages and galleries scale by data updates rather than hardcoded UI rewrites.
- Used route-level metadata exports (`meta()`) to improve discoverability and social sharing quality for each page.
- Designed components with Material UI breakpoint patterns to ensure clean behavior from small mobile screens to large desktops.
